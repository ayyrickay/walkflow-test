## FizzBuzz Example

A simple Python implementation of the classic FizzBuzz problem has been added as `fizzbuzz.py`.

### Usage

Run the script with Python 3:

```bash
python fizzbuzz.py
```

This will print numbers from 1 to 100, substituting multiples of 3 with "Fizz", multiples of 5 with "Buzz", and multiples of both with "FizzBuzz".

This example can be used as a test artifact or demonstration within the repository.
