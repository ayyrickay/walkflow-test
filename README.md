# walkflow-test

This repository contains implementations and tests related to the FizzBuzz problem.

## Running the FizzBuzz Test Suite

A test suite has been added to verify the correctness of FizzBuzz implementations.

### Requirements

- Python 3.x
- pytest (install via `pip install pytest`)

### How to run tests

From the repository root, run:

```bash
pytest test_fizzbuzz.py
```

This will execute the test cases and display clear pass/fail results.

### Adding your own FizzBuzz implementation

Replace or modify the `fizzbuzz` function inside `test_fizzbuzz.py` with your own implementation to validate it against the test suite.
