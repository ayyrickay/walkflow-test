# walkflow-test

This repository contains various test and example scripts to demonstrate and validate workflows.

## Examples

### FizzBuzz

A simple Python example that prints numbers from 1 to 100 with the following rules:
- For multiples of 3, prints "Fizz"
- For multiples of 5, prints "Buzz"
- For multiples of both 3 and 5, prints "FizzBuzz"

To run the example:

```bash
python examples/fizzbuzz.py
```

This example serves as a straightforward demonstration of basic functionality and can be used as a test case for workflows.
