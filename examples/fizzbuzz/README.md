# FizzBuzz Example

This directory contains a simple FizzBuzz example implemented in Python.

## Running the example

Make sure you have Python 3 installed.

Run the script from the command line:

```bash
python examples/fizzbuzz/fizzbuzz.py
```

The script will print numbers from 1 to 100 with the following rules:
- Multiples of 3 are replaced with "Fizz"
- Multiples of 5 are replaced with "Buzz"
- Multiples of both 3 and 5 are replaced with "FizzBuzz"

This example serves as a minimal, canonical test case for the walkflow-test repository.
